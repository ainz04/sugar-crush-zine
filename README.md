# SUGAR CRUSH // ARC 2025 — Interactive Y2K Pop-Zine

Interactive Y2K / Harajuku print-poster web experience featuring custom AI die-cut photography, halftone magazine textures, draggable stickers, WebAudio tactile sound effects, and an HTML5 Canvas Poster Studio with PNG export.

## Features
- **Interactive Magazine Cover**: Wall-to-wall condensed yellow block typography (`SUGAR CRUSH`) with 3D crimson print extrusion, handwritten marker script, 3D mouse parallax, draggable Kawaii Red Bow & Narutomaki stickers, interactive 8-bit pixel hearts HP counter, and laser barcode scanner.
- **5 Die-Cut Lookbook Archive**: Asymmetric magazine spread showcasing 5 custom AI-segmented, zine-graded sticker cutouts with live print filter modes and detail inspection modal.
- **Sugar Crush Poster Lab**: Live interactive 4:5 poster creator canvas — swap cutouts, edit block & marker headlines, switch print palettes, stamp/drag/scale stickers, and export high-resolution PNG posters.

## Deploy on Vercel
Import this repository directly in [Vercel](https://vercel.com/new) — zero build configuration required (`Framework Preset: Other`).
